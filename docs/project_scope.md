# TargetScope — Project Scope

## Project overview

TargetScope is an open-source bioinformatics project for reproducible identification and prioritization of candidate cell-surface therapeutic targets in cancer.

The initial biological use case is multiple myeloma, with a focus on single-cell RNA-seq analysis and evidence integration relevant to antibody-based therapeutics.

## Research question

Can single-cell gene expression, normal tissue expression, protein localization and existing target evidence be integrated into a transparent framework for prioritizing candidate antibody-accessible targets in multiple myeloma?

## Objectives

1. Identify and evaluate a suitable public scRNA-seq dataset.
2. Develop a reproducible analysis workflow using Python and R.
3. Investigate expression patterns in relevant malignant and normal cell populations.
4. Integrate external evidence from resources such as Open Targets and Human Protein Atlas.
5. Develop an interpretable target prioritization framework.
6. Evaluate robustness, sensitivity and known biological reference targets.
7. Publish documented, tested and reusable code on GitHub.

## Scientific principles

- Statistical methods and biological assumptions must be explicitly documented.
- Biological replicates must be respected; individual cells must not be treated as independent patients.
- RNA expression is not sufficient evidence of cell-surface protein availability.
- Missing evidence must not be interpreted as negative evidence.
- Target rankings are hypothesis-generating, not experimental validation.
- Results must be reproducible without relying on generative AI.

## AI usage policy

AI coding tools may assist with implementation, testing, debugging, documentation and software review.

AI must not independently interpret biological results, determine scientific conclusions or modify statistical methods without explicit human approval.

All scientific outputs must be generated by deterministic, documented computational workflows.

## Technical constraints

- Development on macOS with 8 GB RAM.
- Python and R as primary languages.
- CPU-compatible workflows.
- No required paid AI APIs or cloud computing.
- Large datasets excluded from Git version control.

## Initial scope (MVP)

A reproducible workflow that loads a suitable public multiple myeloma dataset, performs appropriate QC and differential expression analysis, integrates selected target evidence and produces a transparent candidate prioritization table.

## Out of scope

- Antibody sequence generation or affinity prediction.
- Training large foundation models.
- Experimental target validation.
- Clinical recommendations.
- Autonomous AI interpretation of biological findings.

## Success criteria

A reviewer can clone the repository, install the documented dependencies, run automated tests, reproduce a small example and understand the data provenance, statistical assumptions, prioritization criteria and limitations.
